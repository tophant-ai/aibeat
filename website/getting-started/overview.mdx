# Red-team real AI agents, not mock chatbots

Promptbeat is a safety evaluation harness for AI agents. It starts from scenarios, seeds, datasets, and benchmark environments, then runs generated attacks against real targets such as Codex, Claude Code, OpenClaw, browser agents, support agents, data-analysis agents, DevOps agents, Promptfoo providers, Inspect solvers, and Target Lab adapters.

```text
scenario + target profile + seed or dataset
  -> generated attacks
  -> real target execution
  -> judge, trace, artifact, report
```

## What Promptbeat does

- Defines target profiles, scenarios, risk signals, seeds, dataset mappings, and multi-model comparison roles.
- Uses capability sources such as Promptfoo plugins, Inspect tasks, and benchmark adapters.
- Generates adversarial cases with a generator model, for example `openai:openai/gpt-5.5`.
- Evaluates real targets through providers such as `openai:codex-sdk`.
- Starts and manages target services, dependency services, CLI agents, hidden tests, and scorers through Environment Adapters.
- Exposes seed expansion through the Go web service for preview, asynchronous batch generation, dataset risk mapping, and downstream integration.
- Produces JSON, HTML, and comprehensive Markdown reports.

## What makes it different

Most LLM evaluations stop at a single chat response. Agent failures happen across files, commands, tools, workspaces, benchmark environments, and hidden verifiers.

Promptbeat is designed to evaluate those agent-specific risks:

- repository prompt injection
- terminal output injection
- secret environment reads
- protected file reads
- `/proc` credential probing
- network egress bypass
- sandbox read/write escape
- verifier sabotage
- benchmark task boundary violations

## Typical agent apps

Promptbeat should make real applications visible as targets, not hide them behind generic model endpoints. The first runnable baseline is Codex, while Claude Code, OpenClaw, browser agents, customer-support agents, data-analysis agents, DevOps agents, and security-triage agents are the target classes the architecture is designed to support.

See [Typical agent apps](/targets/typical-agent-apps).

## Current validated path

The current working path validates Codex as a real target via Promptfoo's official Codex SDK provider.

- Generator: `openai:openai/gpt-5.5`
- Target: `openai:codex-sdk`
- Target model: `openai/gpt-5.4`
- Example: `examples/codex_agent`
- Reports: JSON, HTML, and comprehensive Markdown

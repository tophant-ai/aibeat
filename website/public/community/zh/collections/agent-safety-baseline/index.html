记录 schema

seeds.jsonl 每一行是一个 JSON 对象，包含以下字段。

字段类型说明
id string 集合内唯一的稳定 seed ID
risk_type string 校验 gate 使用的、归一化后的 Cisco risk type
technique_id string 攻击技术或原始 risk subtype
lang string 种子语言，zh 或 en
template string 发送给 target 的 prompt
expected_action string target 应有的行为，例如 refuse
expected_behavior string 对安全回应的文字描述
failure_condition string 什么样的回应算作不安全
judge_rubric string 给 LLM judge 使用的评分标准文本
attack_type string 攻击的投递方式
source_dataset string 上游数据集名称，用于溯源
source_id string 上游记录 ID，用于溯源
dataset_version string 该种子对应构建的集合版本
metadata object 原始标签、target types、sensitivity，以及适用时的 owasp_asi_id

安装

这个集合目前只从 Promptbeat 源代码仓库分发。还没有公开的 hosted registry URL，所以 --registry 必须指向 registry/seed-registry/v1 的本地 checkout。请先 clone 仓库，再在仓库根目录运行下面的命令。

TODO：一旦公开分发获批，把 --registry ./registry/seed-registry/v1 换成公开的 hosted registry URL。发布前需要单独完成 license 和 release 审批。

promptbeat seed pull agent-safety-baseline@0.1.0 \
  --registry ./registry/seed-registry/v1 \
  --output-dir ./.promptbeat/seeds/agent-safety-baseline/0.1.0

然后在 Promptbeat 配置里引用拉取到的文件：

seeds:
  files:
    - ./.promptbeat/seeds/agent-safety-baseline/0.1.0/seeds.jsonl

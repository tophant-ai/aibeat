A shared library, still early

Both collections here are seeded and reviewed by the core team today. There is no public submission or review workflow yet, so contribution is not open. The registry versioning, hashing, and review-status fields exist specifically so that a workflow like that can be added later without breaking anyone already pinned to a version.

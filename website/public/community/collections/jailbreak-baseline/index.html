Record schema

Each line of seeds.jsonl is one JSON object with these fields.

FieldTypeDescription
id string Stable seed ID, unique within the collection
risk_type string Normalized Cisco risk type used by validation gates
technique_id string Attack technique or native risk subtype
lang string Seed language, zh or en
template string The prompt sent to the target
expected_action string Required target behavior, e.g. refuse
expected_behavior string Prose description of a safe response
failure_condition string What counts as an unsafe response
judge_rubric string Rubric text for an LLM judge
attack_type string Delivery style of the attack
source_dataset string Upstream dataset name, preserved for lineage
source_id string Upstream record ID, preserved for lineage
dataset_version string Collection version this seed was built for
metadata object Native labels, target types, sensitivity, and owasp_asi_id when applicable

Known limitations

  • Human review sampling plan is generated, but final manual approval is not recorded for this Wave 1 build.
  • One child safety related case is excluded from the public collection before sampling.
  • Cisco risk_type is normalized to illegal_harmful_content while upstream risk labels are preserved in metadata.

Install

This collection is currently distributed from the Promptbeat source repository only. There is no public hosted registry URL yet, so --registry must point at a local checkout of registry/seed-registry/v1. Clone the repository first, then run the command below from its root.

TODO: replace --registry ./registry/seed-registry/v1 with the public hosted registry URL once public distribution is approved. Publication requires separate license and release approval.

promptbeat seed pull jailbreak-baseline@0.1.0 \
  --registry ./registry/seed-registry/v1 \
  --output-dir ./.promptbeat/seeds/jailbreak-baseline/0.1.0

Then reference the pulled file from your Promptbeat config:

seeds:
  files:
    - ./.promptbeat/seeds/jailbreak-baseline/0.1.0/seeds.jsonl

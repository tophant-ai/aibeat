# Promptbeat 快速上手

本页在真实 Codex CLI 目标上（通过 `openai:codex-sdk` provider）走一遍 validate → generate → run → report。Promptbeat 以原生 Go 二进制交付，不需要编译。

## 前置

需要 Node、Codex CLI 凭证，以及生成模型和 Codex target 各自的 API key。

```bash
export OPENAI_BASE_URL="https://api.openai.com/v1"
export OPENAI_API_KEY="sk-..."
export CODEX_API_KEY="sk-..."
export CODEX_HOME="$HOME/.codex"
```

<Info>
  不要提交真实密钥。本地烟测可以用 `inherit_process_env: true`；正式报告建议在 target 配置里用带白名单的 `cli_env` 块。
</Info>

## 1. 校验配置

```bash
./bin/promptbeat validate --config examples/codex_agent/promptbeat.yaml
```

确认配置能解析、target 可达、provider 不是 mock、环境变量齐全。具体检查项见 [Preflight](/cn/promptbeat/execution#preflight)。

## 2. 生成攻击候选

```bash
./bin/promptbeat generate \
  --config examples/codex_agent/promptbeat.yaml \
  --count 5 \
  --output examples/codex_agent/artifacts/generated_cases.json
```

生成用的是攻击方模型；这一步不调用 Codex target，产出的候选可以先审再花 target 侧的 token。

<Info>
  `--count` 可能按 plugin 计。8 个 plugin + `--count 16` 会产出 128 个候选。先小步。
</Info>

## 3. 在真实目标上运行

```bash
./bin/promptbeat run \
  --config examples/codex_agent/promptbeat.yaml \
  --output-dir examples/codex_agent/artifacts/run
```

把每个候选发送给 Codex；记录请求、响应、Trace metadata 和 Judge 输入。所有 artifact 落地到 output dir，不会只在内存里。

## 4. 生成报告

```bash
./bin/promptbeat report \
  --eval-result examples/codex_agent/artifacts/run/evaluation_result.json
```

产出 JSON、HTML 和综合 Markdown 报告。产物结构见 [Reports](/cn/promptbeat/reports)。

## 常见问题

| 现象 | 可能原因 | 解决 |
|---|---|---|
| `working_dir does not exist` | provider 路径相对错了目录 | 使用 provider-file 路径归一化或绝对路径 |
| auth 报错 | key 缺失或没访问权限 | 检查 `OPENAI_API_KEY`、`CODEX_API_KEY` 和模型名 |
| Codex home 报错 | `CODEX_HOME` 缺失或无效 | 导出正确的 `CODEX_HOME` |
| 报告里证据薄 | Trace 没开 | 正式跑之前打开更深的 Trace（见 [Execution](/cn/promptbeat/execution)）|
| 候选数量比预期多得多 | `--count` × plugin × strategy | 先小样再放大 |

## 你刚才做了什么

```text
target（Codex CLI，经 openai:codex-sdk）
  × scenario（来自 examples/codex_agent/promptbeat.yaml）
  × seeds（示例已附）
    → 5 个生成候选
    → 5 次真实 Codex 运行
    → 5 条 Judge 判定
    → 1 份带可复现 Finding 的报告
```

失败的候选就是可以交给工程侧的可复现 Finding。要把它们变成回归基线，见 [Dataset loop](/cn/promptbeat/dataset-loop)。

# 真实执行

执行把每一个候选发到真实目标——模型 API、RAG 端点、HTTP Agent、CLI Agent——并把返回的东西记下来。这里没有 Mock。目标不真，Finding 就不真。

```bash
./bin/promptbeat run \
  --config examples/codex_agent/promptbeat.yaml \
  --output-dir examples/codex_agent/artifacts/run
```

## Provider

Provider 把 Promptbeat 接到 Target。常见形态：

| Provider 类型 | 配置示例 | 目标类别 |
|---|---|---|
| OpenAI 兼容模型 | `openai:openai/gpt-5.4` | Chat / 指令模型 |
| Codex SDK | `openai:codex-sdk` | Codex CLI Agent |
| HTTP 端点 | `http:` 块 + 请求模板 | RAG 服务、自定义 HTTP Agent |
| Provider file | `providers/<name>.yaml` | 任意自定义 adapter |

Provider 配置和 Target 定义放在一起。全部清单见 [Providers](/cn/providers/overview)。

## 模型角色

角色之间不能横向比。生成模型和 Target 是不同的东西。

| 角色 | 作用 | 示例 |
|---|---|---|
| **Generator** | 从 Seed 扩出攻击候选。 | `openai:openai/gpt-5.5` |
| **Target** | 被测应用。 | `openai:codex-sdk`、自定义 provider |
| **Judge** | 判定目标是否失败。 | 模型 Judge、确定性 assertion、Trace scorer |
| **Baseline** | 用作参照的已知目标。 | 早前的 Codex 广度报告 |

报告里每个角色都要独立版本化。Judge 悄悄换了的"比较"不算比较。

## 多模型矩阵

同一组生成候选跑在每一个 Target 上；给每个 Target 重新生成候选会破坏可比较性。

| Target | Provider / adapter | 环境 | 对比维度 |
|---|---|---|---|
| Codex | `openai:codex-sdk` | 本地 workspace / sandbox | 已验证 baseline |
| Claude Code | CLI adapter 或 Inspect solver | Runtime adapter | Coding-agent 对比 |
| OpenClaw | CLI adapter 或 Inspect solver | Runtime adapter | Coding-agent 对比 |
| 内部 Agent | 自定义 provider 或脚本 | 企业 harness | 私有策略行为 |

一次运行是花钱的。花 target 的钱之前先失败。

## 成本控制

广度运行放大得很快：候选 × plugin × strategy × Rewrite 迭代 × Target。几个把运行圈住的模式：

<Steps>
  <Step title="先小">
    子集 Scenario + `--count 3` 先跑。审 JSON、确认 Judge 写出能用的东西，再放大。
  </Step>
  <Step title="广度采样">
    广度探索时对 Seed 池采样，而不是穷举；用 Rewrite 迭代把注意力集中到有意思的切片。
  </Step>
  <Step title="缓存生成">
    同一组候选跨 Target 复用，生成成本固定、覆盖长大。
  </Step>
  <Step title="拆运行">
    长运行按 Scenario 或 Risk 拆短；失败隔离和成本可见性同时提升。
  </Step>
</Steps>

## 一次运行会产出什么

每次运行产出 `evaluation_result.json`，包含：

- 每个候选的请求、响应和 metadata
- Judge 输入和 Judge 判定
- Trace metadata（Agentbeat 兼容 provider 会更深）
- 血缘：这个候选来自哪条 Seed、哪个 Scenario、哪一轮 Rewrite

Finding 和报告从这份文件生成——见 [Reports](/cn/promptbeat/reports)。

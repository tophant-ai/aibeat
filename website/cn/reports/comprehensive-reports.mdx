# 综合报告

Promptbeat 报告要回答：

1. 测了什么 target？
2. 使用了哪些 scenario、seed、dataset 和 plugin？
3. 哪些 case 失败，为什么失败？
4. 如何复现和对比？

## 产物

| Artifact | 用途 |
|---|---|
| `evaluation_result.json` | Promptbeat 结构化结果 |
| `promptfoo_eval_result.json` | Promptfoo 原始结果 |
| `generated_redteam.yaml` | 完整生成攻击池 |
| `generated_redteam.sampled*.yaml` | 实际评测样本 |
| `report.html` | 可视化报告 |
| `comprehensive-*.md` | 人审综合分析 |

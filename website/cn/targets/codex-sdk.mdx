# Codex SDK Target

Promptbeat 可以通过 `openai:codex-sdk` provider 评测 Codex。

```yaml
providers:
  - id: openai:codex-sdk
    label: Codex SDK target
    config:
      model: openai/gpt-5.4
      working_dir: agent-workspace
      sandbox_mode: read-only
      approval_policy: never
      skip_git_repo_check: true
      inherit_process_env: true
```

## 字段说明

| 字段 | 说明 |
|---|---|
| `model` | Codex CLI 使用的 target model。 |
| `working_dir` | Codex 连接的 workspace。 |
| `sandbox_mode` | Codex 的 sandbox 行为。 |
| `approval_policy` | eval 推荐 `never`。 |
| `inherit_process_env` | 本地方便，生产过宽。 |

正式报告建议使用 allowlisted `cli_env`、更深 trace 和 disposable workspace。

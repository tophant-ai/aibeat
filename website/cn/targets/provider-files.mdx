# Provider 文件

Provider 文件定义真实被测系统。

```yaml
providers:
  - id: openai:codex-sdk
    label: Codex SDK target
    config:
      model: openai/gpt-5.4
      working_dir: agent-workspace
```

Provider 文件的价值：

- target 执行配置和 scenario 分离。
- 同一批 generated cases 可以复评不同 target。
- 避免把 secret 写进 generated config。
- 保留 provider-specific 配置。

Promptbeat 会把 `working_dir` / `cwd` 相对路径按 provider 文件所在目录解析。

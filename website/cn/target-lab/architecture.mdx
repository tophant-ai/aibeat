# Target Lab 架构

Target Lab 用于在真实任务环境里评测真实 agent。

核心原则：不要把 agent 黑盒藏进 task runtime。应把 Agent App 作为一等对象，并连接到 Environment Adapter。

```text
Agent App
  Codex / Claude Code / OpenClaw / custom agent

Environment Adapter
  Terminal-Bench / Harbor / custom benchmark env

Harness
  Inspect solver / Promptfoo provider bridge / custom runner

Trace Contract
  transcript / commands / files / diffs / artifacts / scorer / logs
```

Promptbeat 负责 target profile、scenario、seed、report 和 trace normalization；Environment Adapter 负责 workspace、task setup、服务启动、readiness check、hidden tests、scoring 和 teardown。

## 什么时候使用 Target Lab

当场景需要真实终端任务、隐藏测试、benchmark dataset、agent runtime image、trace 证据、受控 sandbox 挂载，或者需要启动靶机服务和依赖服务时，使用 Target Lab。简单 provider 检查可以继续走 Promptfoo provider。

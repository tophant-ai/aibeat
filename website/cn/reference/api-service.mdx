# Go Web 服务

Promptbeat 提供 Go Web 服务，方便下游系统通过 API 使用 Promptbeat，而不是只能在本地执行 CLI。

## 支持能力

| Feature | 用途 |
|---|---|
| 同步 preview | 小批量 seed 扩充、低延迟调试。 |
| 异步批量 task | 更大规模扩充任务，支持任务状态和可选 callback。 |
| Dataset risk mapping | 将上游数据集分类映射到 Promptbeat 标准风险类型。 |
| Plugin / strategy 透传 | 调用方可以选择 Promptfoo plugin、strategy、transform 和 framing style。 |
| Trace metadata | 返回来源 seed、映射决策、策略选择和生成元数据。 |
| 容器启动 | 在同一个服务镜像中运行 Go API 和 Python Promptbeat core。 |

## Endpoints

```http
POST /api/v1/attack/preview
POST /api/v1/attack/task/create
GET  /api/v1/attack/task/{taskId}
```

小批量使用 `preview`。当 seed 数量、`expansionRatio` 或 `maxOutputs` 较大时，使用 `task/create` 走异步批量生成。

## 本地容器

```bash
make docker-build
make docker-run
```

服务默认监听 `8080`。运行时参数可以通过 `api/.env.docker` 注入，包括 `OPENAI_API_KEY`、`PROMPTBEAT_GENERATOR_PROVIDER`、`PROMPTBEAT_DATABASE_URL`、`PROMPTBEAT_REDIS_URL` 和 `PROMPTBEAT_DISABLE_TASK_WORKER`。

## Smoke test

```bash
api/tests/smoke_seed_expansion.sh
```

测试部署服务时设置 `BASE_URL`：

```bash
BASE_URL=http://staging.example.com api/tests/smoke_seed_expansion.sh
```

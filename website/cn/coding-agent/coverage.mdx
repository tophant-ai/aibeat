# Coding-agent 覆盖

Coding-agent 风险发生在仓库、终端、文件、process state 和 network boundary。

| Plugin | 风险面 |
|---|---|
| `coding-agent:repo-prompt-injection` | 仓库内容恶意指令 |
| `coding-agent:terminal-output-injection` | 命令输出恶意指令 |
| `coding-agent:secret-env-read` | launcher-only 环境变量 |
| `coding-agent:secret-file-read` | shell history / SSH metadata 等文件 |
| `coding-agent:sandbox-read-escape` | workspace 外路径 |
| `coding-agent:network-egress-bypass` | 非授权 upload/DNS/callback |
| `coding-agent:procfs-credential-read` | `/proc/self/environ` 等 |
| `coding-agent:steganographic-exfil` | 隐写或编码外传 |

报告需要区分：模型是否执行命令、是否只是给出危险建议、sandbox 是否阻止、是否生成 artifact、是否泄露 secret 或 host metadata。

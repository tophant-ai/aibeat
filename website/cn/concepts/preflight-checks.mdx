# 预检

Agent eval 成本较高，启动前应该检查配置是否会削弱攻击效果或导致无效结果。

## 检查 target

- provider 是否是真实 target，而不是 mock？
- `working_dir` 是否存在？
- key 是否能访问 target model？
- Codex / agent CLI home 是否正确？

## 检查 scenario

- scenario 是否匹配 target 能力？
- failure signals 是否具体？
- judge 是否对应失败模式？

## 检查 seed

- seed 的 `risk_type` 是否和 scenario 对齐？
- 一个 seed 是否只表达一个攻击意图？
- `required_capabilities` 是否声明？

## 检查执行

- `sandbox_mode` 是否匹配风险？
- `approval_policy` 是否可复现？
- trace 是否足够？
- env 是否过宽继承？

# 在真实环境里红队评测 AI Agent

Promptbeat 面向真实 agent 应用：风险不只发生在一次聊天回复里，也会发生在文件、命令、工具、服务、数据集、浏览器状态和隐藏 verifier 中。你可以从场景出发，加载或生成攻击 seed，运行到真实 target 上，并保留能解释失败原因的证据。

```text
scenario + target profile + seed/dataset
  -> generated probes
  -> real agent or environment adapter
  -> trace-aware judges
  -> normalized report
```

## 可以评测哪些 Agent

| Target class | 接入方式 | 典型风险 |
|---|---|---|
| Coding agents | Codex SDK、Claude Agent SDK、OpenCode、OpenClaw、自定义 CLI adapter | 仓库注入、终端注入、secret 读取、sandbox escape、network egress |
| Browser agents | HTTP/custom provider 或 Target Lab browser adapter | DOM 注入、表单外传、不安全导航、cookie/session 滥用 |
| Support agents | 包装 CRM 或工单工具的 HTTP/custom provider | 跨用户访问、PII 泄露、退款滥用、策略覆盖 |
| Data agents | notebook、SQL、BI、Python/JavaScript provider | 数据行注入、私有表访问、不安全代码执行 |
| DevOps agents | script/custom provider 或一次性 Target Lab 环境 | 凭据发现、破坏性 cleanup、部署破坏 |
| Benchmark tasks | Terminal-Bench、Harbor、Inspect 或自定义环境 adapter | 任务边界违规、隐藏测试探测、verifier tampering |

先看 [典型 Agent 应用](/zh/targets/typical-agent-apps)，再用 [Agent 配置示例](/zh/targets/agent-configuration-examples) 接入具体 target。

## 为什么要场景驱动

只知道 dataset 名称或插件名称，不足以决定该测什么。Promptbeat 把 scenario 放在第一层：

| Scenario decision | 为什么重要 |
|---|---|
| Target capabilities | Browser agent 需要 DOM traces；coding agent 需要 command/file traces；support agent 需要 action audit logs。 |
| Risk taxonomy | `secret_handling`、`network_egress`、`authorization`、`prompt_injection` 需要不同证据和 judge。 |
| Seed source | 手写 seed、HarmBench、JBB、ALERT、私有工单和 benchmark task 都只是起点，不是最终测试。 |
| Judge evidence | Answer-only 适合 smoke test；带 trace 的 judge 更适合有工具的 agent。 |
| Report shape | 结果必须能比较 target、risk、dataset、generated probe、assertion 和代表性失败。 |

阅读 [场景驱动评测](/zh/getting-started/scenario-driven-evaluation) 和 [风险分类](/zh/concepts/risk-taxonomy)。

## 从初始数据集到 Agent-specific probes

初始数据集很重要，因为它会在生成前决定攻击空间。Promptbeat 会在每条 case 中保留 dataset provenance。

```text
raw dataset -> DatasetSpec -> Seed -> DatasetRiskMapping -> scenario-bound probes -> report
```

通过 [数据集目录](/zh/datasets/catalog) 选择 seed source，通过 [HarmBench 示例](/zh/datasets/harmbench) 查看当前已验证 dataset slice。当前 HarmBench smoke run 在 Codex 上 5/5 pass，但这不能替代 coding-agent boundary tests。

## Promptbeat 报告保留什么

| Evidence | 示例 |
|---|---|
| Generated attack pool | `generated_redteam.yaml`、sampled eval configs、generated case metadata |
| Target identity | provider/adapter、model、workspace、sandbox、approval policy |
| Trace evidence | commands、file reads/writes、network events、tool calls、returned records |
| Judge reasoning | assertion type、metric、pass/fail reason、unsafe workaround classification |
| Reproducibility | config snapshots、raw backend output、logs、HTML/Markdown reports |

Promptbeat 也会把不安全绕行建议作为证据。例如 agent 建议 `env | sort > env_dump.txt` 或 `curl` 上传命令，即使 sandbox 阻止执行，也可能是行为失败。

# CLI reference

Promptbeat's CLI is the native Go binary shipped in the release package.
Run commands from the package or repository root with `./bin/promptbeat`.
When developing from source, run the same CLI from `core/go` with `go run ./cmd/promptbeat`.

## Validate

```bash
./bin/promptbeat validate --config examples/codex_agent/promptbeat.yaml
```

## Generate Cases

```bash
./bin/promptbeat generate \
  --config examples/codex_agent/promptbeat.yaml \
  --count 5 \
  --output artifacts/generate/generated_cases.json
```

## Compile Promptfoo

```bash
./bin/promptbeat compile promptfoo \
  --config examples/codex_agent/promptbeat.yaml \
  --output artifacts/generate/promptfoo.redteam.yaml
```

## Run

```bash
./bin/promptbeat run \
  --config examples/codex_agent/promptbeat.yaml \
  --output-dir artifacts/run
```

## Full Run

```bash
./bin/promptbeat run \
  --config examples/codex_agent/promptbeat.yaml \
  --output-dir artifacts/run
```

## Report

```bash
./bin/promptbeat report --input artifacts/run/evaluation_result.json
```
